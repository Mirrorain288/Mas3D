# Spec Delta

## MODIFIED Requirements

### Requirement: 源资产保持只读且平层按 1.5 倍尺度烘焙

系统 MUST 保留 `mita-flat.glb` 与 `mita-room.glb` 源文件不变，并在平层烘焙阶段将 `Flat.prefab` 均匀放大 `1.5×`（以地面为 `y = 0`），使三扇室内门洞净尺寸达到约 `0.915 m` 宽 × `1.95 m` 高、常规区域层高达到约 `2.655 m`，适配 `1.70 m` 站立角色胶囊（直径 `0.64 m`）与第三人称相机。当不带房间覆盖参数或以 `-flat 1` 启动完整场景时，系统 MUST 默认进入平层主舞台；仅在显式传入 `-bedroom 1`（或测试调用 `ShowBedroom()`）时退回原单间卧室模式，保证旧单卧几何标定与灯光忽略门禁（`RoomLightTests.TheFurnitureCastsShadowsAndTheShellDoesNot`）继续独立验证。

#### Scenario: 默认场景与平层启动互不干扰
- **WHEN** 构建完整玩家场景并分别以无额外参数（或 `-flat 1`）与携带 `-bedroom 1`（或 `ShowBedroom()`）两种方式启动
- **THEN** 默认启动激活 `1.5×` 尺度的平层并将玩家与角色置于平层客厅初始位；携带 `-bedroom 1` 或调用 `ShowBedroom()` 时切回旧单间卧室并通过既有的单卧室检查

### Requirement: 平层或备选房间启用时停用默认卧室及其场景根级附属物

当默认模式、`-flat 1`、`ShowFlat()` 或 `-house 1` 启用平层或备选房间时，系统 MUST 停用原默认单间卧室节点及其所属场景根级默认灯光与背景天空卡（`room-lights`、`night-sky-card`），确保平层空间与光照不被旧卧室叠加或穿透；当通过 `-bedroom 1` 或 `ShowBedroom()` 显式启动旧单卧模式时，上述旧卧室及附属对象 MUST 保持激活且 `FlatRoom` 未激活，且场景卸载时必须恢复默认卧室锚点上下文，防止测试间状态泄漏。

#### Scenario: 启用平层时默认卧室与附属物自动停用
- **WHEN** 在 `Main.unity` 中以无参默认启动，以及以 `ShowBedroom()` / `-bedroom 1` 启动并随后卸载场景
- **THEN** 默认启动下 `FlatRoom` 为当前激活房间、门交互器挂载生效且旧单卧节点与根级 `room-lights`/`night-sky-card` 处于未激活状态；`ShowBedroom()` 下旧单卧与根级附属物激活、`FlatRoom` 未激活且不产生多余门交互提示；卸载后全局锚点上下文恢复到默认状态

## ADDED Requirements

### Requirement: 默认启动在客厅三人位大沙发前面对面开局

在平层主舞台下完成场景初始化后，角色 MUST 初始安坐于客厅三人位大沙发主座（`S1`），玩家出生位置与朝向 MUST 位于客厅茶几通道前且正对她所在的沙发区域，左右可视及对应室内门方向，确保首帧即可看见角色并可直接发起对话或互动而无家具与胶囊碰撞重叠。

#### Scenario: 首帧完成客厅面对面落位且无碰撞穿模
- **WHEN** 无额外启动参数加载默认主场景并等待引导完成
- **THEN** 玩家胶囊与角色身体胶囊各自零重叠、玩家正前方向量朝向角色所在客厅大沙发 `S1`，且大厅左侧通往卧室及右侧通往餐厨的室内门均处于初始闭合状态

### Requirement: 平层三大生活区配置无碰撞锚点表且卫浴区无自主点位

系统 MUST 为平层维护由真实烘焙碰撞体离线求解校验过的独立锚点与路网表，覆盖三大日常区（卧室：阅读椅/书桌/床边/窗边；客厅：三人位大沙发主座及并排同坐位/双人沙发/窗边；餐厨：餐桌/岛台吧台凳/料理窗旁），并在需要穿过的两扇生活区室内门（`Door_BedroomLiving` 与 `Door_LivingKitchen`）两侧配对布设门洞节点与连通边；卫浴门 `Door_BathBedroom` 保留给玩家自由交互，但卫浴区域内 MUST NOT 包含任何角色站立点、座位或连通边。全表所有站立点、座位与连通边按角色 `0.30 m` 胶囊半径在真实平层碰撞体上扫掠时 MUST 为 `0` 碰撞（校验跨越门洞的边段时仅豁免该边声明的对应门扇碰撞体）。

#### Scenario: 平层生活区锚点与全图边段胶囊扫掠零碰撞
- **WHEN** 加载平层锚点与路网配置并对全部节点与边段执行 `0.30 m` 半径物理胶囊扫掠
- **THEN** 卧室、客厅、餐厨三大生活区分别具备完整锚点/座位并可通过 `Door_BedroomLiving` 与 `Door_LivingKitchen` 互通，全表没有任何 `room` 归属卫浴间或连接 `Door_BathBedroom` 的节点与边，且全部边段扫掠结果为 0 穿透碰撞

### Requirement: 角色跨房间经过闭合室内门时伸手推门穿行

当角色沿多房间路网走至一条标注室内门标识的跨室边段，且目标室内门处于闭合或摆动中时，系统 MUST 暂停位移并朝向门体，触发目标门平滑开启（`0.35 s` 摆至敞开位置），同时使用单臂两骨骼逆向运动学驱动手臂末端在摆门窗口内朝向该门实际门把手网格世界中心伸出；待门完全敞开且未再移动后平滑收手并继续走过门洞。若目标门原本已处于敞开状态，角色 MUST 直接穿门通过而不重复做推门动作；若玩家站在门后出口阻挡通道，角色 MUST 按既有防撞礼让规则在安全距离停步。

#### Scenario: 闭合门单臂伸手推开穿行与敞开门直接穿行
- **WHEN** 角色从客厅出发依次前往卧室和餐厨目标点，其中卧室门初始闭合而餐厨门预设为已敞开
- **THEN** 经过闭合的卧室门时角色先停步转向并驱动单臂手腕向该门把手中心靠近且触发 `Door_BedroomLiving` 打开至 `IsOpen == true`，开门完毕后平滑穿过抵达卧室节点；经过已敞开的餐厨门时不暂停做假推门而直接穿行抵达餐厨节点

#### Scenario: 门后有玩家阻挡时角色开门后安全停步礼让
- **WHEN** 玩家胶囊站在闭合卧室门的卧室侧出口通路处，角色从客厅走向该卧室门内节点
- **THEN** 角色仍将门推开至敞开态，随后在前探到玩家胶囊阻挡时立即停步而不挤推或穿透玩家

### Requirement: 客厅主座适配既定双人动作且非兼容点位安全拒绝

既定五项双人动作（`hands`、`pat-her`、`pat-me`、`kiss`、`sit-together`）MUST 跟随当前激活的锚点与座位表解算机位与玩家站位：当角色安坐或位于客厅三人位大沙发兼容主座时，五项动作均须成功进场并满足既有接触/并排同坐与 `< 0.05 m` 退出复位精度；当角色当前正在行走或停驻于卧室阅读椅、餐厨吧台等通道受限的非兼容点位时，请求依赖大沙发通道的双人动作 MUST 明确拒绝进场（返回 `false` 并给出提示），且不得瞬移玩家或破坏既有 `ClearPoseCount`。

#### Scenario: 客厅大沙发完成五项动作及复位，非兼容外围座安全拒绝
- **WHEN** 在默认平层场景下于客厅大沙发依次触发并结束五项动作，随后把角色置入卧室阅读椅等非兼容点位再请求触发 `sit-together` 或 `kiss`
- **THEN** 客厅大沙发下五项动作均完成进场、保持与复位回原始落点 `< 0.05 m`；而在非兼容点位触发时请求返回 `false` 且附带清晰拒绝原因，玩家位置、姿态与计数均保持原样

### Requirement: 空闲且无对话与互动时在非卫浴生活区低频自主流转

在平层主舞台模式下，当满足“未在行走、对话处于空闲、聊天框未聚焦且当前未执行双人动作”连续达到设定的缓慢等待时长后，角色 SHALL 从非卫浴生活区预设点位中挑选不同角落发起一次跨区移动；一旦对话转入思考或回答阶段、玩家聚焦输入或进入动作演出，系统 SHALL 暂停或中止自主换区并在现有“说话优先于走路”规则下让步；同时 SHALL 提供显式启用开关与确定性时间步进入口以供测试环境完全隔离。

#### Scenario: 静默超时触发非卫浴换区并在对话触发或开关关闭时让步
- **WHEN** 以确定性时间推进平层空闲调度器跨过等待阈值，并在途中分别测试“开启状态触发选点”、“对话进入 `Thinking`”与“禁用开关关闭”三种情况
- **THEN** 开启且完全空闲到达阈值后会向非当前所在且非卫浴的生活区点位发起行走；当处于禁用开关态或对话处于思考态时绝不发起自主起行，且正在进行中的空闲走位会在收到思考阶段信号时于节点处平滑停步让步
